# Avanta Reizen: projectcontext

Productspecifieke kennis. De algemene werkwijze staat in `docs/WERKWIJZE.md`; het technische werkgeheugen in `CLAUDE.md`.
Vul de open punten in voordat er productcode gebouwd wordt (zie `docs/WERKWIJZE.md`, *Zo start je een nieuw project*, stap 3).

## Doel en product
- _Nog in te vullen:_ wat het product is, voor wie, welke modules.
- _Nog in te vullen:_ wat nooit gebouwd wordt.

## Bedrijfsregels
- _Nog in te vullen:_ prijzen, rechten, processen die de code moet kennen.

## Omgeving
- Repo `danieldh00/Avanta-reizen`, hoofdbranch `main`, applicatie in `app/`.
- _Nog in te vullen:_ hosting, database, deploy, servertoegang en wie wat op de server mag draaien.
- Huisstijl: _nog in te vullen_ (kleuren, logo).

## Voorkeuren
- Nederlands, Europe/Amsterdam.
- Exports als Excel (.xlsx), geen CSV, tenzij expliciet gevraagd.
- Term "KPI's" in plaats van "kengetallen" of "cijfers".

## Projectspecifieke werkafspraken
- Elke PR met wijziging in `app/` krijgt een fragment `changes/<naam>.md`; nooit `version` of `app/CHANGELOG.md` aanraken.
- Reviews: de verplichte checks zijn *Claude code review* en *Claude security review*.
